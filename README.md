# インタビューラボ

小学生から使える、汎用的な「模擬インタビュー」の学習用デジタル教材です。

教科書や特定の単元に依存せず、相手を選び、質問し、答えを聞き、さらに質問するというインタビューの基本的な流れを一人で練習できます。

## 公開ページ

https://tt-sensei.github.io/interviews-/

## 特徴

- 5つの身近なテーマから選択
- 模擬インタビュー形式で2回質問
- 相手の答えを読んで次の質問を考える
- 学習記録を印刷・PDF保存・コピー
- 途中の入力はブラウザのlocalStorageに保存
- 外部API・バックエンド・外部フォントなし
- タブレットで使いやすいシンプルなUI

学校や家庭で、実際のインタビュー活動の前の練習、一人での聞く・たずねる練習などに利用できます。
